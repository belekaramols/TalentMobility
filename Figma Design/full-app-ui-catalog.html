27 — Data persistence (implementation note)

Database entities for full test history

  • AssessmentAttempts — UserId, Competency, Technology, SkillLevel, Score, Status, AssignedByUserId (nullable), Source (Self | ManagerAssigned)
  • AttemptQuestions — AttemptId, SortOrder, QuestionStem, OptionsJson, CorrectOptionIndex, SelectedOptionIndex, IsCorrect, AnsweredAtUtc
  • TestAssignments — EmployeeUserId, AssignedByUserId, Competency, Technology, SkillLevel, DueDateUtc, Status (Pending | Completed), AttemptId when done
  • AssessmentConfig — ManualAssignmentEnabled, NotifyEmployee, DefaultDueDays

After submit: API returns summary; GET /api/attempts/{id}/detail returns full Q&A for employee and manager policies.
